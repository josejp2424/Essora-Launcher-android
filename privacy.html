Esta política se aplica a Essora Launcher (paquete org.essora.launcher), desarrollado por Essora Project. La aplicación es gratuita y de código abierto, distribuida bajo GPL-3.0.

1. Datos que utiliza la aplicación

Essora Launcher no requiere crear una cuenta, no muestra publicidad y no integra servicios propios de analítica o seguimiento.

Para funcionar como pantalla de inicio, consulta localmente las aplicaciones instaladas (por ejemplo, nombres, iconos e identificadores de paquete) y guarda en el dispositivo tus preferencias: accesos directos, gestos, temas, fondos de pantalla y selección de iconos. Estos datos no se envían a servidores de Essora ni al repositorio de colaboradores.

Los temas que creás y las imágenes que elegís se almacenan localmente. Solo se comparten con otras aplicaciones si vos lo solicitás, por ejemplo, al exportar o enviar un tema.

2. Permisos y acceso al dispositivo

  • Cámara: el permiso CAMERA se solicita cuando usás por primera vez la linterna opcional. Se utiliza para encender o apagar el flash; esta función no toma fotografías ni graba videos.
  • Fondo de pantalla: SET_WALLPAPER permite aplicar el fondo seleccionado cuando lo pedís.
  • Internet: se utiliza para consultar la lista pública de colaboradores en GitHub cuando abrís esa sección o pulsás Actualizar; no hay consultas periódicas en segundo plano.
  • Aplicaciones e iconos: se consulta la información local necesaria para mostrar accesos directos y detectar paquetes de iconos compatibles. No se utiliza el permiso general QUERY_ALL_PACKAGES.
  • Archivos: los fondos, temas y packs de iconos se eligen con el selector de documentos de Android. La app no solicita acceso general al almacenamiento.

El rol de launcher predeterminado se gestiona mediante los controles del propio Android.

3. Consulta a GitHub y colaboradores

Al abrir el muro de colaboradores o tocar Actualizar, la app solicita por HTTPS el archivo público supporters.json, alojado por GitHub. Guarda una copia local para mostrar la última lista disponible cuando no hay conexión.

GitHub puede recibir tu dirección IP y datos técnicos habituales de la conexión. Essora no incorpora a esa consulta tus contactos, la lista de aplicaciones, tus imágenes, tus preferencias ni un identificador de cuenta.

El muro dentro de la aplicación muestra nombres o apodos y, si corresponde, notas autorizadas. El archivo público de GitHub también puede contener importes y monedas de las donaciones, aunque esos importes no aparezcan en el muro de la app. La publicación se realiza únicamente con autorización expresa de cada colaborador.

Si querés corregir o retirar un reconocimiento, podés solicitarlo por el repositorio de soporte. No publiques datos bancarios ni información sensible en una incidencia pública. La retirada del archivo actual no elimina automáticamente copias descargadas ni versiones anteriores del historial público de Git.

4. Donaciones mediante PayPal

Si tocás Apoyar Essora, Android abre el enlace externo paypal.me/essoralinux en tu navegador o en una aplicación compatible. Essora Launcher no procesa pagos, no guarda datos bancarios ni lee tu cuenta de PayPal.

Los datos que ingreses al realizar una donación se gestionan mediante PayPal, de acuerdo con sus propias condiciones y su política de privacidad. Las donaciones son voluntarias y no desbloquean funciones, contenido o ventajas digitales.

5. Almacenamiento, conservación y eliminación

Las preferencias, los temas personalizados y la copia de la lista de colaboradores permanecen en el almacenamiento de la app hasta que los eliminás, borrás los datos de Essora Launcher o desinstalás la aplicación, según corresponda. Android puede respaldar algunos datos de aplicaciones mediante sus funciones de copia de seguridad, según la configuración de tu dispositivo.

Los paquetes exportados o compartidos quedan bajo control del usuario y de la aplicación receptora. Los nombres y datos autorizados publicados en GitHub se mantienen hasta que el responsable actualice o retire la entrada; las copias locales de la lista se reemplazan al volver a actualizarla.

6. Seguridad, terceros y contacto

La consulta al archivo de GitHub utiliza HTTPS y valida el tamaño y formato de la respuesta. Los datos locales se guardan en el espacio privado de Android. La app no incluye un SDK de anuncios ni un SDK de pago.

Los servicios externos implicados son GitHub (alojamiento de código y archivo público de colaboradores) y PayPal (solamente cuando decidís abrir el enlace externo). Esta página no incluye cookies propias, scripts de analítica ni rastreadores; su alojamiento en GitHub Pages puede generar registros técnicos de acceso.

Responsable: Essora Project. Para consultas de privacidad, correcciones o solicitudes de retiro, utilizá GitHub Issues de Essora Launcher, sin incluir información sensible en público.

Esta política describe Essora Launcher 1.0.29. Si cambian las funciones o el tratamiento de datos, actualizaremos esta página.

English

This policy applies to Essora Launcher (package org.essora.launcher), developed by Essora Project. The application is free and open-source software licensed under GPL-3.0.

1. Information used by the app

Essora Launcher does not require an account, does not display advertisements, and does not include its own analytics or tracking services.

To work as a home screen, the app reads locally available information about installed applications (such as names, icons and package identifiers) and stores your preferences on the device: shortcuts, gestures, themes, wallpapers and icon selections. This information is not sent to Essora servers or to the supporters repository.

Custom themes and images you select are stored locally. They are only shared with other apps when you explicitly choose to export or share a theme.

2. Device permissions and access

  • Camera: the CAMERA permission is requested when you first use the optional flashlight feature. It controls the flash LED; this feature does not capture photos or videos.
  • Wallpaper: SET_WALLPAPER allows the app to apply a wallpaper when you request it.
  • Internet: used to fetch the public supporters list from GitHub when you open that screen or tap Refresh; there are no periodic background requests.
  • Apps and icon packs: local app details are used for shortcuts and compatible icon pack discovery. The broad QUERY_ALL_PACKAGES permission is not requested.
  • Files: wallpapers, themes and icon packs are selected through Android's system document picker. The app does not request broad storage access.

Setting the default home app is handled through Android's own controls.

3. GitHub requests and public supporters

When you open the supporters wall or tap Refresh, the app downloads the public supporters.json file from GitHub over HTTPS. A local copy is kept so the latest available list can be shown offline.

GitHub may receive your IP address and routine connection metadata. Essora does not attach your contacts, installed-app list, images, preferences or an Essora account identifier to that request.

The in-app wall displays approved names or nicknames and optional notes. The public GitHub file may also contain donation amounts and currencies, even though these amounts are not displayed in the app. An entry is published only with the supporter's express consent.

To request a correction or removal, contact the developer through the support repository. Do not include financial or other sensitive information in a public issue. Removing an entry from the current file does not automatically remove previously downloaded copies or earlier revisions in Git history.

4. Voluntary donations through PayPal

When you tap Support Essora, Android opens the external paypal.me/essoralinux address in your browser or a compatible app. Essora Launcher does not process payments, store bank details or read your PayPal account.

Information provided when making a donation is handled by PayPal under its own terms and privacy policy. Donations are optional and do not unlock features, content or digital benefits.

5. Storage, retention and deletion

Preferences, custom themes and the cached supporters list remain in the app's storage until you remove them, clear Essora Launcher app data or uninstall the app, as applicable. Android may back up some application data through its system backup features, depending on your device settings.

Exported or shared theme packages are controlled by the user and receiving application. Approved public supporter entries remain on GitHub until the maintainer changes or removes them; local cached lists are replaced on refresh.

6. Security, third parties and contact

The GitHub request uses HTTPS and checks response size and format. Local files are stored in Android's app-private storage. The app does not include an advertising SDK or payment SDK.

The external services involved are GitHub (source hosting and public supporters file) and PayPal (only when you choose to open the external link). This webpage has no first-party cookies, analytics scripts or trackers; GitHub Pages hosting may generate technical access logs.

Developer: Essora Project. For privacy questions, corrections or removal requests, use Essora Launcher GitHub Issues, without posting sensitive information publicly.

This policy describes Essora Launcher 1.0.29. We will update this page if app features or data practices change.
