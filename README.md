# Essora Launcher

![Essora Launcher — Coffee theme](screenshot/Lanzador%20Essora_%20Tema%20Caf%C3%A9.png)

Essora Launcher is a lightweight Android home screen written in native Java. It features a minimal interface with rounded app shortcuts, an integrated clock and battery indicator, customizable gestures, and themes.

Developed by Essora Project and released under the GNU GPL-3.0 license.


## Features

- Customizable application bubbles and five-button bottom dock.
- Integrated clock, date, and battery indicator.
- Eleven built-in themes: Essora Color, Black, Green, Pink, Yellow, Hex, Peaks, Sunset, Zen, Autumn, and Coffee.
- Optimized wallpapers and theme previews.
- Essora Green is the default theme for new installations.
- Configurable gestures, including swipe up to open the app drawer and double-tap to toggle the flashlight.
- Essora Theme Creator: create and customize themes with wallpapers, colors, icons, author information, and credits.
- Import, export, and share `.essoratheme` files through Android's native sharing system.
- Install themes manually from local storage.
- Support for compatible ADW/Nova icon packs, including Arcticons.
- Individual custom icons and Essora ZIP icon packs.
- Eleven interface languages: English, Arabic, Catalan, German, Spanish, French, Italian, Portuguese, Hungarian, Russian, and Japanese.
- No permanent background service or external UI framework.

## Google Play Protect

Essora Launcher is not currently available on Google Play.

When installing an APK downloaded from GitHub, Google Play Protect may request a security scan because the application or build has not yet been verified.

A scan request does not necessarily mean the application is harmful. However, if Play Protect displays a harmful-app warning or blocks installation, please report the details so I can investigate the issue.

Essora Launcher is still being tested. Once testing is complete, I hope to submit it to Google Play.

There is no confirmed release date or approval at this time.

More information: [Google Play Protect warnings for developers](https://developers.google.com/android/play-protect/warning-dev-guidance).

## Themes and Icons

Essora Launcher includes a built-in theme creator that allows users to design and share their own themes.

Each `.essoratheme` package can contain:

- Theme name, author, version, and credits.
- Custom colors and appearance settings.
- Wallpaper and preview image.
- Custom application icons.
- GNU GPL-3.0 license information.

Themes can be shared directly through applications such as Telegram and WhatsApp or installed manually from downloaded files.

Compatible external icon packs are referenced rather than included in shared themes. Users must install the required icon pack separately.

Third-party wallpapers and icon artwork retain their original licenses and attribution requirements.

See [Theme and icon pack formats](FORMATOS-DE-TEMAS.md) and [Security and permissions](SEGURIDAD_Y_PERMISOS.md).
